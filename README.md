# Хвиля — особистий музичний плеєр

Музика з YouTube Music: пошук, рекомендації, мікси, плейлисти, тексти пісень, черга, таймер сну.

## Запуск
1. Двічі клацни `start.bat` (перший запуск сам встановить усе потрібне).
2. У вікні з'являться дві адреси:
   - на цьому ПК: `http://localhost:8000`
   - з телефону (та сама Wi-Fi): `http://192.168.x.x:8000`
3. Якщо Windows спитає про брандмауер — дозволь доступ у **приватних мережах**.

## На головний екран телефону
- **iPhone (Safari):** «Поділитися» → «На екран Додому».
- **Android (Chrome):** меню ⋮ → «Додати на головний екран».

Музика грає у фоні та керується з екрана блокування і навушників.

## Як досягається миттєве перемикання
- Сервер наперед завантажує 3 наступні треки на диск (`data/audio`, до 2 ГБ, старі видаляються).
- Телефон тримає 2 наступні треки в пам'яті — перемикання займає ~60–90 мс.
- Перший трек із нуля стартує за ~3–4 с (стільки YouTube віддає посилання).

## Дані
- Лайки, плейлисти й історія зберігаються на телефоні та синхронізуються з сервером (`data/library.json`) — тож вони однакові на всіх пристроях.
- Резервна копія: Налаштування → «Експорт бібліотеки».

## Налаштування через змінні середовища
- `PORT` — порт (типово 8000)
- `CACHE_MB` — розмір аудіокешу (типово 2000)
- `YTM_LOCATION` — регіон рекомендацій (типово UA)
