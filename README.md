# Хвиля — особистий музичний плеєр

Музика з YouTube Music: пошук, рекомендації, мікси, плейлисти, тексти пісень, черга, таймер сну.

**Сайт:** https://nazya-why.github.io/hvylia/

## Як це працює
- **Сайт** (папка `web/`) лежить на GitHub Pages.
- **Сервер** (`server.py`) працює на твоєму ПК: шукає музику й віддає звук.
  Він відкриває безкоштовний HTTPS-тунель Cloudflare і записує його адресу в секретний gist,
  тож сайт сам знаходить сервер навіть після перезапуску ПК.
- Доступ через тунель захищений ключем (`data/key.txt`), запити з домашньої мережі ключа не потребують.

## Запуск
1. Один раз встанови cloudflared: `winget install Cloudflare.cloudflared`
   і увійди в GitHub CLI: `gh auth login`.
2. Двічі клацни `start.bat`.
3. У вікні з'явиться QR-код — відскануй його телефоном **один раз**. Далі просто відкривай сайт.

Без тунелю сайт працює в домашній Wi-Fi за адресою `http://<IP-ПК>:8000`.

## На головний екран телефону
- **iPhone (Safari):** «Поділитися» → «На екран Додому».
- **Android (Chrome):** меню ⋮ → «Додати на головний екран».

## Миттєве перемикання
- Сервер наперед кешує 3 наступні треки на диск (`data/audio`, до 2 ГБ).
- Телефон тримає 2 наступні треки в пам'яті — перемикання ~50–90 мс.
- Перший трек із нуля стартує за ~3–4 с.

## Змінні середовища
`PORT` (8000), `CACHE_MB` (2000), `YTM_LOCATION` (UA), `TUNNEL=0` — вимкнути тунель, `PAGES_URL` — адреса сайту.
